# dashboard/

Carpeta final lista para entregar.

## Contenido
- `index.html`: dashboard con las 6 preguntas de negocio.
- `hefesto.html`: resumen de la metodología.
- `paso1.html` a `paso4.html`: resumen de cada entrega.
- `etl.html`: explicación simple del ETL (sin backend ni conexión web a MySQL).
- `assets/`: gráficos usados por el sitio.

## Publicación en Render
Tipo: Static Site

- Build Command: dejar vacío
- Publish Directory: `.`

La web es estática y no necesita backend.
